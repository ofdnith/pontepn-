Released on October 29, 2026.

Fix for the Switch app: some games downloaded only a few megabytes, the screen said the install was complete, and nothing was installed.

## Download

| File | For | How to install |
|---|---|---|
| `ponte.nro` | Switch (Atmosphère) | Replace `/switch/ponte/ponte.nro` on the SD card. This is the file that changed. |
| `Ponte-Mac.zip` | Mac (macOS 13 or later) | Same as 1.0.0; only the version number changed. Updating is optional. |
| `ponte.elf` | PS5 (firmware 13.60, with etaHEN) | Same behavior as 1.0.0; only the version number changed. Updating is optional. |
| `SHA256SUMS.txt` | — | File hashes, to check the download. |
| `LICENSE-*.txt` | — | Licenses: 0BSD for Ponte, GPLv3 for `ponte.nro` (Sphaira engine; source in `switch/app/` of this repository). |

## What changed

**Switch: an install that installs nothing no longer says "complete".** The installer reads the start of the file and decides whether to skip each content. When it skipped everything, it still ended successfully, so Ponte showed "Installation complete!" after a few megabytes. Now:
- Ponte no longer skips a game because the system's content database says it is "already installed". That database can keep leftovers of a game that was deleted or whose install was interrupted. Whether the game is on the console is decided by the Mac, from the console's list of applications.
- If nothing was installed, the item ends as a failure, on screen and in the Mac's history, with the reason (for example, a newer update is already installed, or "skip base" is on in the install options).

**Tested on real hardware**: the Switch app (screen, reading what is installed, installing) and the PS5 payload (copying a folder and an `.exfat` to `homebrew/`). One folder game only launched after being converted to `.exfat`; if a folder game crashes, try converting it in the Mac app (Settings → convert PS5 folders to `.exfat`).

### O que mudou

**Switch: instalação que não instala nada não diz mais "concluída".** O instalador lê o começo do arquivo e decide se pula cada conteúdo. Quando pulava tudo, terminava com sucesso mesmo assim, e o Ponte mostrava "Instalação concluída!" depois de alguns megabytes. Agora:
- O Ponte não pula mais um jogo porque o banco de conteúdos do sistema diz que ele "já está instalado". Esse banco pode guardar restos de um jogo apagado ou de uma instalação interrompida. Quem diz se o jogo está no console é o Mac, pela lista de aplicativos do console.
- Se nada foi instalado, o item termina como falha, na tela e no histórico do Mac, com o motivo (por exemplo, já há uma atualização mais nova instalada, ou a opção "pular base" está ligada nas opções de instalação).

Um jogo em pasta só abriu depois de convertido para `.exfat`; se um jogo em pasta fechar sozinho, tente convertê-lo no app do Mac (Ajustes → converter pastas de PS5 em `.exfat`).
